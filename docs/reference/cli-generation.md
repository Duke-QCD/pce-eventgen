# Generation, setup, and shared helpers: source argument index

[Command guide](commands.md) · [Handbook](../README.md)

Generated by `python3 tools/build_docs.py`; edit the source help or the guide, then regenerate. Tables list argument **declarations**, including shared helpers, hidden options, and all subcommands together. An option in a table does not necessarily belong to every subcommand. Use `COMMAND SUBCOMMAND --help` for accepted combinations. Dynamic expressions are shown unevaluated.

Parser context names the subcommand when directly declared, otherwise the source parser variable and helper function. Shared helpers/loops can supply the same option to multiple commands.

`default=None` can mean a later INI/environment fallback; it is not the resolved campaign default. Required values may be supplied by the shared INI where supported. Missing `type` normally means text; `store_true` and `store_false` are Boolean switches; `nargs` controls value count.

The standard `-h, --help` is implicit in argparse. Options added in loops are shown once as their source declaration. See shared-helper entries in [generation](cli-generation.md) for status/config arguments used by other tools.
